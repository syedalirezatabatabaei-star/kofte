# Kofte — Finca front-end snapshot

این مخزن برای نگهداری و اصلاح تدریجی فرانت‌اند فینکا مرتب شده است.

## ساختار فعلی

- `index.html`: ساختار HTML و خروجی SSR صفحه اصلی
- `css/finca.css`: تمام ۳۵ بلوک CSS درون‌صفحه‌ای استخراج‌شده از HTML، با حفظ ترتیب اصلی
- `css/fonts.css`: تعریف فونت‌های محلی موجود در مخزن
- `css/main.css`: استایل مستقل موجود در پروژه؛ فعلاً به صفحه اصلی متصل نشده تا ظاهر نسخه فعلی ناخواسته تغییر نکند
- `js/main.js`: اسکریپت مستقل موجود در پروژه؛ فعلاً به صفحه SSR متصل نشده تا رفتارهای نمونه با اپ اصلی تداخل نکنند
- `font/`: فایل‌های فونت
     
## فونت‌های متصل‌شده

- Yekan Bakh Regular / Medium / Bold
- Lahzeh FaNum Bold

فونت Lahzeh Medium و فونت‌های کمکی مانند JetBrains Mono، Poppins و KaTeX در فایل‌های فعلی مخزن موجود نیستند؛ ارجاع‌های اصلی آن‌ها دست‌نخورده باقی مانده‌اند.

## نکته مهم درباره اجرای کامل صفحه

این فایل یک snapshot از HTML رندرشده فینکا است. خود صفحه هنوز به فایل‌های build شده Nuxt با مسیر `/_nuxt/` و فایل‌های `/polyfill.min.js` و `/metrix-bridge.js` ارجاع می‌دهد که در حال حاضر داخل این مخزن نیستند. بنابراین جداسازی HTML/CSS به‌تنهایی به معنی مستقل شدن کامل برنامه یا فعال بودن تمام تعاملات نیست. برای اجرای کامل باید assetهای build اصلی نیز در مخزن قرار بگیرند.

## ادامه توسعه

تغییرات ظاهری جدید را به‌صورت مرحله‌ای در فایل‌های مستقل انجام بدهید و قبل از حذف یا جایگزینی assetهای snapshot، وابستگی‌های آن‌ها را بررسی کنید.


## Footer social dock

نوار شبکه‌های اجتماعی فوتر با ظاهر شیشه‌ای و آیکون‌های squircle پیاده‌سازی شده است. کد فقط از HTML، SVG و CSS خام استفاده می‌کند و وابستگی به Tailwind یا هر فریم‌ورک دیگری ندارد. لینک لینکدین همان صفحه رسمی قبلی فینکا است؛ لینک گیت‌هاب، یوتیوب و دیسکورد فعلاً به صفحه اصلی سرویس‌ها اشاره می‌کنند و باید پس از مشخص شدن آدرس رسمی حساب‌ها جایگزین شوند.
